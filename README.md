# Gitflow Lab Project

This repository demonstrates the Gitflow workflow and Git merge conflict resolution.

## Branches

- main - Production-ready code
- develop - Integration branch
- feature/user-login - User login feature
- feature/cart - Shopping cart feature
- feature/wishlist - Wishlist feature
- release/1.0 - Release preparation
- hotfix/1.0.1 - Production hotfix

## Features

- User login
- Shopping cart
- Wishlist
- Shared navigation

## Lab Tasks

### Task 1
Create feature/user-login from develop and merge it back using `--no-ff`.

### Task 2
Create feature/cart and feature/wishlist from develop. Both features modify `nav.html` to demonstrate merge conflict resolution.
